# Your AI Swarm Is Already Waiting

You know what you want your agent to do. The blocker is infrastructure, not imagination.

You want a research assistant that monitors topics overnight. A support agent that handles client questions while you sleep. A content helper that drafts and refines on demand. The agent logic is the easy part — you could write the instructions in ten minutes.

The hard part is everything else: message routing across channels, persistent state between sessions, LLM orchestration, workspace lifecycle, idle shutdown, cold starts, tool sandboxing. Weeks of infrastructure work before your agent handles a single message.

Wireclaw handles all of it. You configure an agent through the dashboard, connect a channel, hit deploy. Your agent runs 24/7.

## Who This Is For

**Solopreneurs replacing virtual assistants.** Deploy an agent that handles research, customer inquiries, or scheduling — available around the clock for a fraction of what you pay a VA. Configure it once, it works while you focus on building.

**Freelancers deploying agents for clients.** Each client gets their own agent with isolated memory, per-client cost controls, and dedicated channels. You configure and deploy through the dashboard — the client interacts through Telegram, Discord, or Slack.

**Indie hackers shipping agent-powered products.** Build AI into your product without managing LLM infrastructure. Wireclaw handles model routing, state persistence, and channel integration. You focus on the product logic.

## What You Can Do

**Run 100 agents at zero idle cost.** Agents wake on demand when a message arrives, restore their full workspace from the last session, do the work, and go back to sleep. You pay only for active compute — no always-on servers, no per-agent fees.

**Give your agent persistent memory.** Your agent remembers past conversations, learned context, and stored findings across sessions. Close the chat today, pick up where you left off next week. Memory persists through workspace dehydration to S3 and full restoration on wake.

**Use any model.** Claude, GPT, Gemini, DeepSeek, Llama, Mistral, Grok — switch models from a dropdown in the dashboard. No code changes, no migration. The Sulaert model router handles provider abstraction.

**Extend with MCP tools.** Connect custom MCP servers to give your agent access to databases, internal APIs, browser automation, or specialized tools. Add them in the dashboard and redeploy.

**Deploy across channels.** Telegram, Discord, Slack — connect one or many. A single agent can serve multiple channels, sharing the same memory and context. A user starts a conversation on Discord, references it from Telegram. The agent knows.
